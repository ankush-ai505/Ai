# E-commerce Web App

This project is a full-stack e-commerce web application where users can browse products, add items to cart, place orders, and make payments online.

## Tech Stack
- **Backend:** Python + FastAPI
- **Frontend:** React + TypeScript
- **Database:** PostgreSQL
- **Containerization:** Docker

## Features
- Product browsing
- Cart management
- Order placement
- Payment integration

## Project Structure
```
ecommerce-app/
├── backend/
├── frontend/
├── shared/
├── docker-compose.yml
├── README.md
```

## Running the Project
1. Clone the repository.
2. Navigate to the `ecommerce-app` folder.
3. Run `docker-compose up`.
4. Access frontend at `http://localhost:3000` and backend at `http://localhost:8000`.
